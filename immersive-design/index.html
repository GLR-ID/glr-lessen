VR Architectuur Richtlijnen

  • Schaalgetrouwheid: Handhaaf strikt 1 unit = 1 meter. Verkeerde schaal veroorzaakt desoriëntatie.
  • Geen Vaste Screen-Space UI: Plaats UI-elementen uitsluitend als World Space objecten in de 3D-wereld.
  • Strikte 90 FPS Norm: Dropping frames veroorzaakt fysieke misselijkheid. Bewaak de 11.1ms frame limiet.
  • Ontkoppel Input van Logica: Gebruik Unity Input System Actions in plaats van hard-coded controller keys.
